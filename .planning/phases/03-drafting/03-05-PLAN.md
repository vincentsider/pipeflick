  <behavior>
Add to `src/prompts.ts` — no imports, primitives only, every threshold a named exported constant
(the 03-01 rule: the tuning levers live in one place, never inline at a call site):

```ts
export type GroundingReport = {
  /** Every reported citation resolves against the source pool, normalised. */
  citationsResolved: boolean;
  /** Claim-bearing sentences the pool supports / how many were examined. */
  supported: number;
  checked: number;
  /** Sentences with no material support, verbatim as the post wrote them. */
  unsupported: string[];
  /** Phrases the post repeats that appear nowhere in the pool. */
  repeated: string[];
  /** Sentences too short or too generic to judge. Reported, never hidden. */
  skipped: number;
  /** citationsResolved && unsupported.length === 0 && repeated.length === 0 */
  grounded: boolean;
};

export function normaliseForMatch(text: string): string;
export function splitSentences(text: string): string[];
export function checkGrounding(post: string, sourceLines: string[], sources: string[]): GroundingReport;
```

`sources` is the executive's own material: `[transcriptBody, ...voiceSampleBodies]`. Outlier
bodies must NEVER be passed in — the FORMAT block carries shape only, so an outlier's phrasing
turning up in a draft is a defect, not grounding. Say so in the doc comment.

**Cases the behaviour must satisfy** (the first two are verbatim production failures, already
recorded in `.planning/todos/pending/normalise-grounding-match.md`, so they are safe to commit):

*False negative — must now resolve:*

| Model reported | Transcript actually says |
|---|---|
| `In the short terms you have to choose your battle, right?` | `Meaning in the short terms you have to choose your battle, right?` |
| `The two combined make your website authoritative and visible.` | `And that the two combined make your website authoritative and visible.` |

*False positive — must now be caught:*
A post containing `Collect the prompts. Build authority. Become visible.` twice, where that
phrase appears zero times in the sources, must come back `grounded: false` with the phrase in
`repeated` — even when all three citations resolve cleanly.

*Preserved from `isGrounded`:*
- No citations at all → `citationsResolved: false`, `grounded: false`.
- A whitespace-only citation → does not resolve. (`"".includes("")` is always true; a naive
  check scores an empty citation as grounded. 03-01 got this right; keep it right.)

*New behaviour:*
- A sentence genuinely rephrased from transcript words (same content words, different order or
  connectives) counts as supported via shingle overlap, not exact match.
- A sentence shorter than `GROUNDING_MIN_CLAIM_TOKENS` counts toward `skipped`, not `checked`
  — "Here is the thing." is connective tissue, not a claim, and flagging it would recreate the
  noise problem in a new costume.
- An invented sentence of real length ("Studies show 60% of firms fail at this.") appears in
  `unsupported` verbatim as the post wrote it, so the reviewer can find it on the page.
  </behavior>

  <implementation>
**`normaliseForMatch`** — applied to both sides before any comparison:
1. Normalise unicode punctuation to ASCII: curly quotes `' ' " "` → `' "`, `–` `—` → `-`.
2. Lowercase.
3. Collapse all whitespace (including newlines) to single spaces, trim.
4. Strip a leading connective from `LEADING_CONNECTIVES` (export it): `meaning`, `and that`,
   `and`, `so`, `but`, `right`, `you know`, `i mean`, `like`, `well`, `okay`, `now`. Longest
   match first, and only at the very start. Strip repeatedly (up to 2 passes) — "And that the
   two combined" needs `and that` gone, and "so and" happens in speech.
5. Strip leading and trailing punctuation.

**Token helpers:** `tokens(text)` = `normaliseForMatch(text)` split on non-word characters,
empties dropped. Shingles are contiguous `GROUNDING_SHINGLE_TOKENS`-length token runs.

**Support decision for one sentence** (`supportedBy(sentence, pool)`):
1. Fast path: the normalised sentence is a substring of the normalised pool → supported. (This
   alone flips the two draft-1 citations.)
2. Otherwise: fraction of the sentence's shingles present in the pool's shingle set
   `>= GROUNDING_SUPPORT_RATIO` → supported.
3. Fewer than `GROUNDING_SHINGLE_TOKENS` tokens after the min-claim filter → fall back to the
   substring test only.

Normalise the pool ONCE per `checkGrounding` call and reuse it; do not re-normalise per
sentence. This runs inside the 10ms Free-plan CPU budget for a ~220-word post against a
~18,000-character pool.

**`splitSentences`** — split on `\n` first, then on `.`/`!`/`?` followed by whitespace or
end. Keep the raw (un-normalised) text of each piece, because `unsupported` must be quotable
back to the user exactly as the post wrote it. Drop empty pieces.

**Repeat detection** (`repeated`): build a count of every `GROUNDING_REPEAT_TOKENS`-gram in the
post's token stream. Take the n-grams with count >= 2 that are absent from the pool, then merge
overlapping ones into the longest contiguous phrase, and return each distinct phrase once.
Sentence-level repetition detection is NOT enough here and must not be used: the real failure
was `Collect the prompts.` / `Build authority.` / `Become visible.` — three sentences of 3, 2
and 2 tokens, each below any sensible claim threshold. The n-gram stream crosses those
boundaries and catches the 7-token run. This is why the constant is a token count, not a
sentence count.

**Constants** (exported, starting values — calibration below may move them, and a moved value
gets a one-line comment saying what moved it):
```ts
export const GROUNDING_MIN_CLAIM_TOKENS = 6;
export const GROUNDING_SHINGLE_TOKENS = 4;
export const GROUNDING_SUPPORT_RATIO = 0.5;
export const GROUNDING_REPEAT_TOKENS = 6;
```

**One prompt change, and only one.** Add a single line to `DRAFT_INSTRUCTIONS` under "Grounding
rules": `- Never repeat a sentence or phrase verbatim within the post.` The check detects; the
prompt prevents, and prevention is cheaper. Pin the new line in the existing "keeps the
grounding, voice and banned-word rules" test alongside the other load-bearing phrases. Change
nothing else in the instructions — every other phrase there is pinned and load-bearing.

**Leave alone:** `excerptTranscript` (03-06 runs in the same wave and depends on its current
signature), `isGrounded` and its three tests (03-07 removes them), every schema, every other
constant.
