**Step route, drafting branch** — swap the import of `isGrounded` for `checkGrounding` and
replace the `finishDraft` call:
```ts
const sampleBodies = samples.map((sample) => sample.body);
// ... the drafting call, unchanged ...
await finishDraft(
  c.env.DB,
  job.id,
  value.post,
  value.source_lines,
  // The whole post against the executive's own material. The full transcript
  // body, not the excerpt: a superset, so the check is only ever more lenient
  // than what the model was shown. Outlier bodies are deliberately absent —
  // FORMAT carries shape only, so an outlier's phrasing in a draft is a defect.
  checkGrounding(value.post, value.source_lines, [transcript.body, ...sampleBodies]),
  usage,
);
```
Reuse the `samples` already fetched for `buildDraftingInput`; do not add a second
`listVoiceSamples` read. The primitives-only rule at this call site is unchanged and still
load-bearing: pass `transcript.body`, never `transcript`.

**`DraftSection`** — replace the single `grounded === false` warning with a panel driven by
`grounding_json`. Parse it defensively (it is D1 text; a parse failure must render the legacy
case, not throw and take the whole run page down):

- `grounding_json` null → `<p class="hint">Written before the current grounding check.</p>`
  Do not fall back to the stored `grounded` boolean for these rows. That boolean is the proxy
  this plan exists to retire, and re-rendering it would keep the misleading signal alive on
  exactly the drafts already known to carry it wrong.
- `unsupported` or `repeated` non-empty → `<p class="notice warn">` naming what to read, then the
  lines themselves in a list, each in a `.draft-body`-style block so line breaks survive:
  - repeated: `This phrase is repeated and appears nowhere in your transcript or voice samples:`
  - unsupported: `These lines could not be traced back to your own words:`
  - If the stored counts exceed what was kept, append `and N more.`
- Otherwise → `<p class="hint">Traced {supported} of {checked} substantive lines back to your own
  words.</p>`

Then, in every case where a report exists, one more `class="hint"` line:
`{skipped} short or connecting lines were too generic to check.`
This sentence is not decoration. Phase 3 failed its one criterion by letting a narrow check read
as a whole-output guarantee; the page must now say out loud what the check did not examine.

Leave `StepStatus`, `Failure`, `RunControl`, `TemplateSteps` and the coverage line from 03-06
exactly as they are.
