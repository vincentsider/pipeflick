<task type="auto">
  <name>Task 1: Health route with DB round-trip and secret presence</name>
  <files>src/health.tsx, src/index.tsx, .dev.vars.example</files>
  <action>
1. `.dev.vars.example` (committed): three lines `OPENAI_API_KEY=`, `FIREFLIES_API_KEY=`, `METRICOOL_USER_TOKEN=`. If `.dev.vars` does not exist, copy the example to `.dev.vars` (gitignored) so `wrangler types` includes the names in `Env`. Never write real values into the example.
2. Add to `src/access.ts` (or a new `src/env.ts`) a `SECRET_NAMES = ["OPENAI_API_KEY", "FIREFLIES_API_KEY", "METRICOOL_USER_TOKEN"] as const` and make `AppEnv.Bindings` = `Env & Partial<Record<typeof SECRET_NAMES[number], string>>` so the code compiles whether or not `.dev.vars` declares them.
3. `src/health.tsx`: export a `Hono<AppEnv>` sub-app with a shared `runHealth(c)` function returning `{ email, db: { ok: boolean, lastCheck?: string, error?: string }, secrets: Record<name, boolean> }`:
   - DB: `await setSetting(c.env.DB, "health.last_check", new Date().toISOString())` then `getSetting` of the same key; `ok` is true only when the read-back equals the written value. Catch errors and put `String(err)` in `error` so a broken binding is visible on the page rather than a blank 500.
   - Secrets: for each name, `typeof c.env[name] === "string" && c.env[name].length > 0`. Only the boolean leaves this function. Do not log, echo or prefix-print values anywhere.
   - `GET /health`: HTML via `Layout`; a table with rows for DB (ok / error text + last check timestamp) and one row per secret ("set" / "not set"), plus "Signed in as {email}". HTTP 200 when db.ok, 500 otherwise.
   - `GET /health.json`: `c.json(result, db.ok ? 200 : 500)`.
4. Mount in `src/index.tsx` after `app.use("*", requireAccess)`: `app.route("/", health)`.
5. `npm run check`; local check with `wrangler dev`: `curl -s http://localhost:8787/health.json` returns `db.ok: true`, a `lastCheck` ISO string, `secrets` with three booleans, and the simulated email. `curl -s http://localhost:8787/health` contains "not set" or "set" for each name and no key material.
  </action>
  <verify>`curl -s http://localhost:8787/health.json | grep -c '"ok":true'` prints 1; `curl -s http://localhost:8787/health` contains OPENAI_API_KEY, FIREFLIES_API_KEY and METRICOOL_USER_TOKEN; `npm run check` exits 0</verify>
