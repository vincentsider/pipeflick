<task type="auto">
  <name>Task 1: Scope every user-data query in src/db.ts</name>
  <files>src/db.ts</files>
  <action>
    Add `owner: string` to the signature of every function touching the four owned tables, and
    add `AND owner_email = ?n` to its WHERE clause (or the column to its INSERT).

    OWNER IS A REQUIRED PARAMETER, NEVER OPTIONAL AND NEVER DEFAULTED. A default is a silent
    cross-account read the first time a caller forgets it; a required parameter is a compile
    error. That difference is the entire protection.

    The four root tables and their functions:
      settings       — getSetting, setSetting
      transcripts    — upsertTranscript, listTranscripts, getTranscript
      voice_samples  — insertVoiceSample, listVoiceSamples
      runs           — createRun, listRuns, getRunView, setRunStatus, resetRunJobs

    `getRunView` IS THE LOAD-BEARING ONE. Its run lookup must filter by owner and return null
    when the run belongs to someone else. `outliers` and `drafts` carry no owner column by
    design (06-01), so this read is the ONLY door to them. If it does not filter, every child
    read in the app is unscoped and the phase's security claim is false.

    The job functions — claimNextJob, finishOutlier, finishDraft, failJob, recordDecision,
    listApprovedPosts, recordPush, recordPushFailure — operate on children by `run_id`. Do NOT
    add an owner parameter to them. Instead, every ROUTE that calls them must first prove the
    run belongs to the caller via an owner-scoped `getRunView`, and Task 2 enforces that. Write
    this rule as a comment above the job functions so a later reader does not "helpfully" add a
    half-scoped filter that reads as protection and is not.

    `insertPilotRequest` is untouched — landing-page leads belong to the operator.

    Keep `src/db.ts` import-free. It has zero import lines today and that is the boundary that
    keeps prompt-building out of the data layer.
  </action>
  <verify>
    `grep -c '^import' src/db.ts` is 0. Every function listed above takes an owner. No function
    signature has an optional or defaulted owner: `grep -n 'owner.*=.*\"' src/db.ts` finds no
    default values.
  </verify>
  <done>The four owned tables cannot be read or written without an owner argument.</done>
</task>
