<task type="auto">
  <name>Task 1: Fireflies GraphQL client</name>
  <files>src/fireflies.ts</files>
  <action>
    Create `src/fireflies.ts` (no Hono imports; takes the API key as a string so it is testable and never reads env itself):

    - `const ENDPOINT = "https://api.fireflies.ai/graphql"`.
    - `export class FirefliesError extends Error { code: string; status: number }` — `code` is the Fireflies error code (`errors[0].code ?? errors[0].extensions?.code ?? "http_" + status`), message is `errors[0].message` or "Fireflies returned HTTP <status>". Never include the API key, the request body, or transcript text in the message.
    - `async function firefliesQuery<T>(apiKey, query: string, variables?: Record<string, unknown>): Promise<T>`: `fetch(ENDPOINT, { method: "POST", headers: { "Content-Type": "application/json", Authorization: \`Bearer ${apiKey}\` }, body: JSON.stringify({ query, variables }), signal: AbortSignal.timeout(20_000) })`. If `!res.ok` try to parse JSON for `errors`; throw FirefliesError. If the JSON has a non-empty `errors` array, throw FirefliesError even when HTTP is 200 (Fireflies does this). Return `json.data`.
    - `export type Meeting = { id: string; title: string; dateIso: string; durationMinutes: number }`.
    - `export async function listMeetings(apiKey, skip = 0): Promise<{ user: { name: string; email: string }; meetings: Meeting[] }>` — ONE request: `query($skip: Int) { user { name email } transcripts(limit: 50, skip: $skip) { id title date duration } }`. Map `date` (ms epoch Float) → `new Date(date).toISOString()`, `duration` (minutes) → `Math.round`. Missing title → "(untitled)".
    - `export type FetchedTranscript = { id: string; title: string; dateIso: string; durationMinutes: number; sentences: Sentence[] }` (import `Sentence` from ./speaker-filter).
    - `export async function fetchTranscript(apiKey, id): Promise<FetchedTranscript>` — `query($id: String!) { transcript(id: $id) { id title date duration sentences { index speaker_name text raw_text } } }`. `object_not_found` surfaces as FirefliesError with that code.

    No console.log anywhere. Module comment: rate limits are 50 requests/day on the Free plan, so callers make one request per page view.
  </action>
  <verify>
    `npm run check` exits 0. `git grep -n "console\." src/fireflies.ts` is empty. `grep -c "api.fireflies.ai/graphql" src/fireflies.ts` ≥ 1.
  </verify>
  <done>Client compiles, maps Fireflies errors to FirefliesError with code and no secrets, one request per list page.</done>
